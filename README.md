# מאמן ידע – מבחני כושר

אפליקציית תרגול ומבחנים למדריכי כושר (PWA). עובדת גם בלי חיבור לאינטרנט.

## מה יש באפליקציה
- **שני מצבים לבחירה:** 🎮 משחק (מפת מסע עם שלבים, כוכבים ובוסים, מטבעות, עזרים, חנות, קומבו ומשימות יומיות עם תיבת אוצר) או 📚 לימוד. מחליפים בכפתור למעלה
- **298 שאלות ב־10 תחומים**, כולל פסיכולוגיה ומוטיבציה ושאלות עם איורים
- **מצבים:** אתגר יומי, תרגול מהיר, מבחן מהירות, הישרדות, סימולציית מבחן, אתגר חבר, מבחן מותאם, כרטיסיות, חזרה חכמה, טעויות, שמורות ומבחן מונחים
- **למידה:** שיעור קצר לכל תחום, מילון של 99 מונחים, מילים לחיצות ותיבת "❓ לא הבנתי", 98 עובדות "הידעת?" ושומר מסך
- **אוכל:** כותבים מאכל בכל שורה ("מילקי", "2 ביצים", "כוס אורז") ומקבלים קלוריות, חלבון, פחמימות ושומן – 263 מזונות (כולל גרסאות לפני/אחרי בישול), תיקון ערכים לפי תווית ומזונות משלך
- **כלים:** מחשבוני 1RM, דופק מטרה, נפח אימון, BMR/TDEE וחלבון
- **מוטיבציה:** מטרה יומית, רמות, רצף, 22 הישגים, תעודת הצטיינות, גרף ציונים ודוח חולשות
- **תזכורות** עם תדירות לבחירה ושעות שקט

## הוספת שאלה
ב־`questions2.js`, בתוך `BANK.push(...)`:
```js
{f:"anatomy",l:"easy",t:"mc",q:"השאלה?",o:["תשובה נכונה","שגויה","שגויה","שגויה"],a:0,e:"הסבר"},
```
באמריקאיות התשובות מעורבבות אוטומטית, אז הנכונה תמיד ראשונה.

## תזכורות – מה חשוב לדעת
באתר/PWA התזכורות מגיעות בזמן כשהאפליקציה פתוחה או ברקע; כשהיא סגורה – לפי מה שאנדרואיד מאפשר (בערך פעם ביום).
הקוד כבר מוכן ל־**Capacitor** עם התוסף `@capacitor/local-notifications` – בגרסת אנדרואיד מלאה התזכורות יגיעו בדיוק בזמן, בלי לשנות קוד.

- 🌐 **דו־קרב אונליין**: פותחים חדר, מקבלים קוד של 4 ספרות (או קישור), החבר מצטרף, ושניכם עונים על אותן שאלות בזמן אמת. נקודות לפי תשובה נכונה + מהירות.
- 🏆 **לוח מובילים**: לוח חברים (המאזן מול כל יריב), השיאים שלך, ולוח עולמי (אופציונלי).

### איך מפעילים לוח מובילים עולמי (פעם אחת, כ־5 דקות)
1. נכנסים ל־https://console.firebase.google.com ויוצרים פרויקט חדש (חינם).
2. בתפריט: Build → Realtime Database → Create Database → בוחרים מיקום (europe-west1) → Start in **locked mode**.
3. בלשונית Rules מוחקים הכל, מדביקים את התוכן של הקובץ `firebase-rules.json`, ולוחצים Publish.
4. מעתיקים את כתובת המסד (מופיעה בראש הלשונית Data, נראית כך: https://xxxx-default-rtdb.europe-west1.firebasedatabase.app).
5. פותחים את הקובץ `config.js`, מדביקים את הכתובת בין המירכאות של `LB_URL`, ומעלים מחדש ל־GitHub.
כל עוד `LB_URL` ריק – הלשונית "עולמי" פשוט מוסתרת, וכל השאר עובד.
