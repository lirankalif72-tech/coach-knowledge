# מאמן ידע – מבחני כושר

אפליקציית תרגול ומבחנים למדריכי כושר (PWA), עובדת גם בלי חיבור לאינטרנט.

## מה יש באפליקציה
- **161 שאלות** ב־9 תחומים: אנטומיה, פיזיולוגיה, טכניקה, תכנון אימונים, TRX, סיטואציות מהשטח, בטיחות, תזונה ואוכלוסיות מיוחדות
- 3 סוגי שאלות: אמריקאיות, נכון/לא נכון ופתוחות (עם בדיקה עצמית)
- מצבים: אתגר יומי, תרגול מהיר, מבחן מהירות (60 שניות), סימולציית מבחן (30 שאלות, 35 דקות), מבחן מותאם אישית, כרטיסיות, חזרה על טעויות, שאלות שמורות וחזרה חכמה (חזרה מרווחת)
- רמות ו־XP, רצף ימים, 12 הישגים, שליטה לפי תחום
- מילון מונחים עם חיפוש
- מצב כהה ובהיר, צלילים ורטט, גיבוי ושחזור התקדמות

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | שלד הדף |
| `styles.css` | העיצוב |
| `app.js` | הלוגיקה |
| `questions.js` | מאגר השאלות והמילון – כאן מוסיפים שאלות |
| `sw.js` | עבודה בלי חיבור. **בכל עדכון להעלות את מספר הגרסה ב־`CACHE`** |
| `manifest.webmanifest` | הגדרות ההתקנה |
| `privacy.html` | מדיניות פרטיות |

## הוספת שאלה
ב־`questions.js` מוסיפים שורה למערך `BANK`, למשל:
```js
{f:"anatomy",l:"easy",t:"mc",q:"השאלה?",o:["תשובה נכונה","שגויה","שגויה","שגויה"],a:0,e:"הסבר"},
```
באמריקאיות התשובות מעורבבות אוטומטית, אז אפשר תמיד לשים את הנכונה ראשונה.
